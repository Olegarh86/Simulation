# Проект "Симуляция"
---
## Суть проекта
Это пошаговая симуляция 2D мира, населённого травоядными 🐇 и хищниками 🐺. Кроме существ, 
мир содержит ресурсы (траву) 🍀, которыми питаются травоядные, и статичные объекты, с которыми нельзя взаимодействовать - они просто занимают место: 
Дерево 🌱 и камень 💎. 2D мир представляет из себя матрицу 10 * 10 клеток в симуляции по умолчанию, каждое существо или
объект занимают клетку целиком, нахождение в клетке нескольких объектов/существ - недопустимо.
### 🐺 Хищники
Имеют следующие характеристики:
- speed (сколько клеток способен преодолевать за 1 ход) по умолчанию = 1
- hp (количество жизней) по умолчанию = 10
- attackPower (размер урона, наносимого, при атаке жертвы) по умолчанию = 5
---
Хищник перемещается по миру в поисках жертвы, травоядного 🐇. С каждым ходом у хищника уменьшается hp на 1. Когда хищник 
настигает жертву, он атакует её. Количество hp при атаке у жертвы уменьшается на силу атаки хищника, а у хищника 
увеличивается на силу атаки или, если количество hp жертвы меньше силы атаки, то на количество hp жертвы. Когда 
количество hp хищника становится меньше 1, хищник умирает и исчезает с карты. Когда умирает последний хищник, в мире 
появляются 10 новых хищников.
### 🐇 Травоядные
Имеют следующие характеристики:
- speed (сколько клеток способен преодолевать за 1 ход) по умолчанию = 1
- hp (количество жизней) по умолчанию = 10
---
Травоядное перемещается по миру в поисках еды, травы 🍀. С каждым ходом у травоядного уменьшается hp на 1. Когда 
травоядное находит траву, оно поглощает её и травы в мире на 1 становится меньше, а у травоядного увеличивается 
hp на 1. Травоядное атакуют хищники, уменьшая им hp при атаках, как только hp травоядного становится меньше 1, 
травоядное умирает, исчезая из мира. Когда умирает последнее травоядное, в мире
появляются 10 новых травоядных.
### 🍀 Трава
Трава это статичный объект, является пищей для травоядных, в настройках по умолчанию на старте в мире существует 
травы 15 экземпляров. Как только съедают последнюю траву, снова появляется 15 экземпляров травы.
### 🌱 Дерево и 💎 Камень
Это статичные объекты, представляют собой препятствия, которые должны обходить все движущиеся обитатели мира.

## Управление
Можно просто запустить симуляцию и наблюдать за бесконечным ходом событий, а можно вручную управлять процессом симуляции.
Для этого реализованы следующие команды:
- При нажатии любой кнопки симуляция ставится на паузу.
- При нажатии "space" + Enter процесс симуляции заканчивается.
- При нажатии 1 + Enter возобновляется бесконечный процесс симуляции.


### В процессе запуска симуляции можно выбрать создание мира с параметрами по умолчанию или указать параметры мира вручную.
- количество строк в мире, высота карты (по умолчанию 10)
- количество столбцов в мире, ширина карты (по умолчанию 10)
- количество камней (по умолчанию 10)
- количество деревьев (по умолчанию 10)
- количество травы (по умолчанию 15)
- количество травоядных (по умолчанию 10)
- количество хищников (по умолчанию 10)
- количество жизней у травоядных (по умолчанию 10)
- какая у травоядных будет скорость перемещения (по умолчанию 1)
- количество жизней у хищников (по умолчанию 10)
- какая у хищников будет скорость перемещения (по умолчанию 1)
- какая будет сила атаки у хищников (по умолчанию 5)
- количество миллисекунд между ходами всех существ (по умолчанию 500)
